# Práctica de Hacking Ético: Posicionamiento Web y Credential Harvesting

Repositorio institucional académico desarrollado en Debian 13 para la evaluación de técnicas de visibilidad en motores de búsqueda (SEO Poisoning / Long-tail) y su impacto en vectores de ingeniería social.

## Objetivos de la Práctica
- Demostrar las limitaciones del posicionamiento orgánico en páginas de nueva creación frente a dominios institucionales consolidados.
- Evaluar el comportamiento de indexación de rastreadores web (Googlebot / DuckDuckGo) utilizando un archivo `robots.txt` y un `sitemap.xml`.
- Simular un portal de captura de credenciales mediante plantillas corporativas con fines de concientización en ciberseguridad.
